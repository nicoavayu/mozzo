# Admin Sounds

Sonidos usados por el panel admin para alertas operativas.

Origen:
- `new-order-bell.wav`: Mixkit, item 601, "Happy bell alert"
- `request-bill-register.wav`: sonido local de caja registradora usado para `request_bill`
- `call-waiter-bell.wav`: Mixkit, item 1791, "Cooking bell ding"

Licencia:
- Mixkit License
- referencia oficial: https://mixkit.co/license/

Nota:
- en runtime se reproducen desde `frontend/src/lib/adminSoundAlerts.js`
- algunos archivos se recortan o repiten para que funcionen mejor como alerta UI
